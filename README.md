PHONE SHOP

Интернет-магазин телефонов. Покупатель выбирает модель в каталоге, кладёт её в корзину, оформляет заказ и следит за доставкой. Продавец и администратор добавляют телефоны, меняют цены, фото и остатки и видят все заказы. Все данные хранятся в базе Microsoft Access.

Учебный проект. Оплата не подключена: способ оплаты просто записывается в заказ.

Возможности

Каталог

Карточки телефонов: фото, марка, модель, память, ОЗУ, цвет, цена и наличие на складе.
Поиск по модели и фильтр по марке.
Страница телефона с характеристиками и полным описанием.
Главная страница: баннер с фото телефонов, плитки марок, баннеры «Новинка в каталоге» и «Выгодная цена» (подбираются автоматически из каталога).

Покупатель

Регистрация (ФИО, телефон, email, адрес, логин, пароль) и вход.
Корзина: можно собирать без входа, после входа она сохраняется.
Оформление заказа: способ доставки (курьер, почта, самовывоз), адрес и способ оплаты (карта, наличные, рассрочка).
При покупке купленное количество списывается со склада. Купить больше, чем есть, нельзя.
«Мои заказы»: покупатель видит только свои заказы.
Отслеживание заказа: шаги «Оформлен», «В пути», «Доставлен», даты и адрес.

Продавец и администратор (раздел «Управление»)

Добавление телефона: марка из списка или новая, память, ОЗУ, цвет, цена, остаток, описание, фото.
Изменение уже добавленных телефонов, поиск по марке и модели.
Все заказы всех покупателей с итогами: количество и общая сумма.

Быстрый старт

Нужно:

Windows;
Python 3.10 или новее;
драйвер Access (Microsoft Access Database Engine). Разрядность Python и драйвера должна совпадать (64-бит и 64-бит).
powershell
git clone https://github.com/aloew706/telefon.git
cd telefon
pip install -r requirements.txt
python app.py

Перед запуском закройте файл phones.accdb в Access. В PyCharm достаточно нажать Run на файле app.py.

Сайт откроется на http://127.0.0.1:5000.

При старте сайт сам:

создаёт таблицу логины (если её нет) и добавляет тестовые аккаунты;

Как проходит заказ
Покупатель добавляет телефон в корзину. Количество ограничено остатком на складе.
Покупатель входит или регистрируется (корзина сохраняется), выбирает доставку, адрес и оплату и нажимает «Оформить заказ».
Купленное количество списывается со склада. В таблицы заказы и доставка добавляются записи, статус доставки «Оформлен».
Если заказ не удалось записать, товар возвращается на склад.
Статус доставки (В пути, Доставлено, Отменено) и даты меняются в таблице доставка. Покупатель видит их на странице отслеживания.

Таблицы цвет и память пока справочники без связей: цвет и память телефона хранятся прямо в таблице телефоны. В доставка на каждый заказ сайт создаёт одну запись. В логины покупатель связан с таблицей покупатели, а продавец и администратор с продавцы.

Схема в формате draw.io лежит в файле er_diagram.drawio.

Безопасность
Права проверяются на сервере: раздел «Управление» доступен только администратору и продавцу, покупатель видит только свои заказы (чужой заказ открыть нельзя).
SQL-запросы параметризованы, названия таблиц и столбцов берутся из схемы базы, а не из запроса.
Списание товара выполняется условным запросом: остаток не уйдёт в минус, даже если двое покупают последние штуки одновременно.
Фото проверяются по содержимому, а не по расширению. Файлы, которые не являются картинками, не принимаются.
Ошибки базы данных покупателю не показываются, он видит нейтральное сообщение.

Ограничения

Пароли в таблице логины хранятся открытым текстом. Это допустимо только для учебного показа. Для реального сайта нужно хранить хеши.
Нет CSRF-токенов, защита сессии только через cookie SameSite=Lax.
Статусы доставки на сайте не меняются, их правят в Access.
Отменённый заказ не возвращает товар на склад автоматически.
Запуск через встроенный сервер Flask подходит для учёбы и показа, но не для публикации в интернете.
